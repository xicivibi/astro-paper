# 운영 안내 페이지

## 포함된 페이지

- `/about/`: 사이트의 주제 범위와 AI 보조 작성, 원문 확인, 정정 원칙
- `/contact/`: 정정 요청과 문의 안내
- `/privacy/`: 현재 수집 기능이 없다는 사실과 향후 외부 서비스 연결 시 갱신 원칙
- `/editorial-policy/`: 출처, 재현성, 수정, 광고·제휴 표시 원칙
- `/tools/csv-preview/`: 파일을 외부로 전송하지 않고 구분자·레코드 수·일부 행을 확인하는 브라우저 내 CSV 점검 도구

모든 페이지는 공통 헤더, 브레드크럼, 본문, 푸터 레이아웃을 사용하며 푸터에서 서로 접근할 수 있습니다.

## 운영자 정보 런치 블로커

운영자 이름, 법적 사업자 정보, 공개 주소, 공개 문의 채널은 저장소에 제공되지 않았습니다. 이를 추측해 페이지에 넣지 않았습니다. 실제 공개 이름과 이메일이 정해지면 배포 환경에 `PUBLIC_CREATOR_NAME`, `PUBLIC_CONTACT_EMAIL`을 설정하고, 필요하면 `PUBLIC_CONTACT_LABEL`도 설정한 뒤 다시 빌드·배포합니다. 이 값은 정적 빌드 시점에 반영됩니다. 값이 없거나 형식이 올바르지 않을 때 페이지는 `공개 이름 미제공`, `공개 문의 채널 준비 중`을 표시합니다.

## 외부 서비스와 광고

현재 페이지는 광고·방문 통계가 활성화됐다고 주장하지 않습니다. 실제로 이용 중인 Vercel 호스팅, 브라우저의 Pagefind 검색, jsDelivr의 Pretendard 스타일시트 요청을 안내합니다. 향후 분석·광고를 연결하거나 호스팅을 이전하면 실제 제공자와 처리 범위에 맞춰 개인정보 안내를 갱신해야 합니다.

## 검증 기록

- 자동화 테스트 37개 통과, Astro 검사 91개 파일에서 오류·경고·힌트 0개.
- Windows의 기존 `cp` 빌드 단계를 Node `fs.cpSync`로 변경한 후 전체 빌드 성공.
- 전체 정적 빌드 63페이지와 Pagefind 색인 20개 글을 확인했다.
- 로컬 브라우저에서 홈, 주제 허브, 빈 주제 상태, 브리프, 글의 신뢰 패널, 소개, 문의, 편집 정책을 확인했다. 동시 편집 중 발견된 문의·편집 정책의 한글 손상은 UTF-8로 복구한 뒤 최종 빌드 산출물에서 다시 확인했다.

### 공개 운영자 표시 준비 상태

`PUBLIC_CREATOR_NAME`과 `PUBLIC_CONTACT_EMAIL`은 배포 환경에서 선택적으로 주입합니다. 값이 없거나 유효하지 않으면 페이지는 각각 `공개 이름 미제공`, `공개 문의 채널 준비 중`을 표시합니다. 이름·이메일·법적 정보를 추측해 기본값으로 채우지 않습니다.
