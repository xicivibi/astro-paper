# 운영자 경험 문단 작성 가이드

`src/content/pages/operator-experience.md`는 **소유자만** 씁니다. 에이전트나 AI가 대신 쓰면 경험(E-E-A-T의 첫 E)을 꾸며 내는 셈이라 쓰지 않습니다.

## 쓰는 법

1. 본문을 지우고 3~6문장으로 실제 경험을 씁니다.
2. 프론트매터의 `ownerStatus`를 `"written"`으로 바꿉니다.
3. `pnpm run build` 후 `node scripts/adsense-readiness.mjs --mode verify`로 "운영자 경험" 항목이 통과하는지 확인합니다.

## 넣으면 좋은 내용(사실인 것만)

- 어떤 업무에서 엑셀·CSV·구글 시트를 얼마나 오래 다뤘는지(직무명·연차 정도, 회사명은 선택)
- 이 사이트 글의 계기가 된 실제 문제 한두 가지(예: 거래처 CSV의 한글 깨짐, 사번 앞자리 0 손실)
- 재현할 때 쓰는 환경(Excel 버전, 운영체제)
- AI를 어디까지 쓰고 어디부터 직접 확인하는지

## 넣지 말 것

- 확인할 수 없는 자격증·수상·경력, 다른 사람의 경험
- 회사 내부 자료, 고객 정보, 개인 연락처(문의는 환경변수 이메일로만)
