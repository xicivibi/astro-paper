열이 많은 표를 PDF로 저장했더니 오른쪽 열이 다음 장으로 넘어가거나 아예 빠져 있는 일이 있습니다. 인쇄 영역이 일부 열만 가리키는지, 지정이 없어서 열이 장마다 쪼개지는지에 따라 증상이 다릅니다. 이 글은 열 18개짜리 합성 표를 같은 용지 설정에서 세 가지 방식으로 PDF로 내보내고, 페이지 수와 열 분할을 숫자로 비교한 기록입니다.

## 표본과 실행 조건

표는 `Column01`부터 `Column18`까지 18개 열과 데이터 6행으로, 머리글을 포함하면 `A1:R7` 범위입니다. 셀 값은 `S1-C01`처럼 행과 열 번호를 그대로 쓴 합성 값입니다. 열 너비는 모든 열 18, 용지는 A4 세로, 배율은 100%로 고정했습니다.

PDF는 `Worksheet.ExportAsFixedFormat`으로 저장했고, 인쇄 영역 무시 옵션은 모든 실행에서 끄고 두었습니다. 페이지 수는 저장된 PDF 파일 안의 페이지 개체 수를 세어 구했고, 세로 페이지 나누기 개수는 PDF를 저장한 뒤 Excel에서 읽었습니다.

## 잘못된 결과 두 가지

### 인쇄 영역이 A1:F7일 때

인쇄 영역을 `$A$1:$F$7`로 지정하고 배율 100%로 내보냈습니다. 인쇄 영역 밖인 `G`부터 `R`까지 12개 열은 출력 대상이 아닙니다(PDF 안의 글자를 추출해 확인하지는 않았습니다). 눈에 띄는 점은 남은 6개 열조차 한 장에 들어가지 않았다는 것입니다. 페이지 수는 2, 세로 페이지 나누기는 1개였습니다. 열 너비 18, A4 세로, 배율 100%라는 이번 설정에서의 결과이며, 다른 열 너비나 용지에서는 다를 수 있습니다.

### 인쇄 영역이 없을 때

인쇄 영역을 비우고 같은 설정으로 내보냈습니다. 페이지 수는 5, 세로 페이지 나누기는 4개였습니다. 열이 사라지지는 않았지만 18개 열이 5개 구역으로 쪼개져 표 한 줄이 여러 장에 흩어졌습니다. 가로 페이지 나누기는 세 실행 모두 0개였습니다.

## 왜 이렇게 되는가

인쇄 영역은 인쇄할 범위를 정하는 설정이고, Microsoft 문서에 따르면 VBA에서 이 속성에 빈 문자열이나 `False`를 넣으면 시트 전체가 대상이 됩니다. 범위를 좁게 지정하면 나머지는 출력에서 빠지고, 범위가 넓은데 배율을 줄이지 않으면 한 장의 너비를 넘는 열은 새 페이지로 넘어갑니다. 두 문제는 원인이 다르므로 해결 방법도 다릅니다. 앞의 것은 인쇄 영역을 실제 데이터 범위에 맞추는 일이고, 뒤의 것은 배율이나 용지 방향을 조정하는 일입니다.

## 수정: 인쇄 영역을 전체로 맞추고 가로 1쪽에 맞추기

인쇄 영역을 `$A$1:$R$7`로 지정하고, 배율을 끄고 가로 한 쪽 맞춤을 켰습니다. 이때 쓴 설정 값은 다음과 같습니다.

```text
PageSetup.PrintArea = "$A$1:$R$7"
PageSetup.Zoom = False
PageSetup.FitToPagesWide = 1
PageSetup.FitToPagesTall = False
```

Microsoft 문서에 따르면 `Zoom`이 `True`이면 `FitToPagesWide`는 무시되므로 먼저 `Zoom`을 꺼야 합니다. 높이를 `False`로 두면 세로 쪽 수는 자동으로 정해집니다. 결과는 PDF 페이지 수 1, 세로 페이지 나누기 0개였고, 인쇄 영역은 `A1:R7` 전체였습니다.

세 번의 내보내기는 같은 시트에서 설정만 차례로 바꿔 진행했고, 각 설정에서 저장한 PDF와 그 시점의 나누기 개수를 함께 기록했습니다. 설정을 바꾸는 순서 자체가 결과에 영향을 주는지는 따로 시험하지 않았습니다.

## 결과 대조

| 설정 | 인쇄 영역 | 페이지 수 | 세로 페이지 나누기 | 열 분할 |
| --- | --- | --- | --- | --- |
| 부분 인쇄 영역, 배율 100% | `A1:F7` | 2 | 1 | 있음 |
| 인쇄 영역 없음, 배율 100% | 없음 | 5 | 4 | 있음 |
| 가로 1쪽 맞춤 | `A1:R7` | 1 | 0 | 없음 |

Microsoft 지원 문서는 이 기능을 `페이지 레이아웃` 탭의 `크기 조정`(Scale to Fit) 그룹에서 너비를 1페이지로 두고 높이를 자동으로 두는 방법으로 안내하며, 많이 줄이면 읽기 어려울 수 있다고 주의합니다. 이 글의 실행에서는 한 장에 넣은 결과의 글자 크기와 가독성은 확인하지 않았습니다.

## 내 파일에 적용하기 전 확인할 것

- 인쇄 영역이 데이터의 마지막 열과 마지막 행까지 포함하는지 확인합니다.
- PDF로 저장하기 전에 세로 페이지 나누기 개수가 0인지 봅니다. 미리 보는 기능은 Microsoft 문서에 `보기` 탭의 `페이지 나누기 미리 보기`로 안내되어 있습니다.
- 너비 맞춤을 쓰면 배율이 얼마로 줄었는지 확인하고, 글자가 읽히는지 PDF를 직접 열어 봅니다.
- 열이 많으면 용지 방향이나 용지 크기를 바꾸는 쪽이 배율을 낮추는 것보다 읽기 좋은지 비교합니다.
- 저장한 PDF의 페이지 수를 눈으로 세어 기대한 값과 맞춥니다.

## 이 글에서 확인한 범위

- Excel 16.0 빌드 20527, 한국어 UI 환경에서 합성 데이터로 실행한 결과입니다.
- 실행은 데스크톱 Excel을 자동화해 진행했습니다. 리본 메뉴의 클릭 경로는 확인하지 않았고, 이 글의 메뉴 이름은 Microsoft 문서의 안내를 옮긴 것입니다.
- 확인한 값: 페이지 수 2, 5, 1과 세로 페이지 나누기 1, 4, 0개.
- 확인하지 못한 것: 실제 프린터 출력, PDF 안의 텍스트 추출, 한 장에 맞춘 결과의 글자 크기와 가독성. 열 분할 여부는 Excel의 페이지 나누기 개수와 PDF 페이지 수에 근거한 것입니다.
- 열 너비, 용지 크기, 용지 방향이 다른 파일에서는 페이지 수가 달라질 수 있습니다.
