Xici는 사무실에서 매일 마주치는 데이터 파일 문제를 다룹니다. CSV 한글이 깨지거나, 사번의 앞자리 0이 사라지거나, Power Query로 합친 결과가 새로고침할 때마다 달라지는 문제처럼 **결과가 틀려도 겉으로는 멀쩡해 보이는 지점**을 찾아, 다시 따라 할 수 있는 절차로 정리합니다.

## 다루는 범위

- **Excel·CSV**: 가져오기 진단, 식별자 보존, Power Query 결합·정리·비교
- **Google Sheets·Apps Script**: 함수, 설문 응답 정리, 반복 작업 자동화
- **문서·웹 업무**: 업무 문서와 웹 도구를 고르고 연결할 때 확인할 기준

각 글은 하나의 주제 허브에 속하고, 가능한 경우 [무료 브라우저 도구](/tools/)와 함께 제공합니다. 도구는 파일을 서버에 올리지 않고 브라우저 안에서만 처리합니다.

## 글을 만드는 방식

- 핵심 주장마다 Microsoft·Google 공식 문서를 먼저 연결합니다.
- **사람이 직접 재현한 글만 "재현 기록 제공(reproduced)"으로 표기합니다.** 재현한 글에는 합성 입력 파일, 기대 결과와 SHA-256 매니페스트를 담은 재현 키트를 함께 공개합니다. 직접 실행하지 않은 글은 "공식 출처만 제공"으로 표시합니다.
- AI는 자료 정리와 초안 작성을 돕는 도구로 사용합니다. AI가 관여한 글은 글 하단의 작성·검증 정보에 "AI 보조 작성"으로 표시하고, 공개 전에 운영자가 내용을 다시 읽고 검토자와 검토 날짜를 남깁니다.
- 사실과 해석, 재현 결과와 일반적인 조언을 구분해 씁니다. 확인 범위 밖의 환경은 글의 "이 글의 확인 범위"에 따로 적습니다.
- 오류를 발견하면 원문을 다시 확인해 수정하고, 내용에 영향을 주는 정정은 글 안에 표시합니다.

## 바이라인과 운영자

글의 작성자로 표시되는 **직장인 자동화 실험실**은 이 사이트 운영자가 실무 검증 글에 쓰는 이름입니다. 운영자는 한 명이며, 회사나 단체를 대표하지 않습니다. 광고나 제휴가 실제로 운영되면 독자가 알 수 있게 별도로 표시합니다.
